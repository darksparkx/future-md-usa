# FutureMdUSA — pitch preview

A click-through mock of the India launch: marketing website, student platform, and full office software in one Next.js app.

```bash
npm run dev
```

Open [http://localhost:3847](http://localhost:3847).

The top bar switches **Option 1**, **Option 2**, and **Option 3**. Demo records stay in the browser. Reset them from that bar. Nothing here charges a card or calls a live service.

Client source material is in `pitch/` (gitignored).
